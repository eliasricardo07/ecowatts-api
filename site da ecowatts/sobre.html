Como construímos o EcoWatts

Uma união perfeita entre hardware IoT para captação elétrica, backend escalável em Node.js e inteligência de dados na nuvem.

1. Captação na Raiz (IoT)

O coração do hardware é o microcontrolador ESP32, equipado com módulos Wi-Fi nativos. Ele trabalha em conjunto com sensores de corrente não-invasivos (SCT013) e invasivos (ACS712) mapeados para as 4 saídas principais. O ESP32 processa os picos analógicos e os converte em Watt/hora reais.

ESP32 ACS712 / SCT013 C++ / Arduino

Telemetria Contínua

O firmware do dispositivo foi otimizado para não causar gargalos na rede local. Os dados são enviados via HTTP POST em pacotes JSON a cada poucos segundos, garantindo a visualização em tempo real.

Supabase: O Cérebro Relacional

Utilizamos o Supabase (PostgreSQL) para armazenamento seguro das séries temporais. Toda leitura de sensor gera gatilhos que calculam estimativas de custo baseado nas bandeiras tarifárias atuais e estimativas de CO₂.

2. Middleware Nuvem (Node.js)

A API Restful foi desenvolvida em Node.js + Express e hospedada no Render. Esta camada atua como guarda de segurança (Rate Limiting) e orquestrador de regras de negócio. É no backend onde os Watts brutos são transformados em impactos na pegada de carbono e onde as "Gamificações" (Eco Points) são computadas.

Node.js Express API PostgreSQL

3. O Painel de Controle (Dashboard)

O Dashboard foi desenhado seguindo a filosofia de UI "Premium/Futurista". Ele roda integralmente no navegador do usuário conectando-se aos sistemas via JavaScript assíncrono (`fetch`). Os dados ganham vida em milissegundos utilizando Chart.js para renderizar as faturas projetadas e a métrica de gamificação ambiental.

HTML5 / CSS3 Vanilla JS Chart.js

UX Responsiva

O sistema busca continuamente por atualizações (Polling). Quando o microondas da casa é ligado, os sensores enviam a carga para o servidor, e o gráfico do painel pisca e se move sozinho.
